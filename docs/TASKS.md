# 整层地图优化任务

## 本轮

- [x] 1. 整层地图与持久状态：6 个房间、走廊、双向门、自由往返；敌人/奖励/泉水状态持久化；安全攒、跨房保留能量和反击；独立新版存档。
- [x] 2. 探索与导航：视野遮挡、地形记忆、小地图；只沿已探索路面自动寻路，每步推进一拍，遇敌/新危险/受伤/手动输入即停。

## 追击、探索与成长

- [x] 3. 跨房追击与能力生命周期：追击最后已知位置、搜索与脱战；回响按攒次数，护心按层次数。
- [x] 4. 探索取舍：钥匙与锁门支路、一次性补给、烟雾/诱饵/回血等战术道具。
- [x] 5. 战斗与成长：最终伤害预览、敌人组合、反击/蓄能/穿透构筑、后续楼层难度提升。

## 暂缓

- [ ] 6. 复盘与调优：图鉴、死因回顾、真人游玩时长与空走比例、难度与操作反馈。

## 已确认原则

玩家可以准备充分再开战。安全攒也推进世界一拍，能量有上限、跨房保留，脱战不衰减；暂不加入饥饿或攒能量的额外噪声惩罚。旧版本存档不覆盖。
